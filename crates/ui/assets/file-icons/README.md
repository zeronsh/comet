# Symbols assets

These icons are copied from
[`miguelsolorio/vscode-symbols`](https://github.com/miguelsolorio/vscode-symbols)
at commit `296ef1b62287fb2315cb5651e552e09e8c8e1de8` and embedded into the native
application at compile time. `src/file-icons.json` is the matching upstream VS
Code file-icon theme manifest.

The source project is MIT licensed; its license is retained beside the assets
in `LICENSE.symbols`.
